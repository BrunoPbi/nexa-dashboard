# nexa-dashboard
 Interactive Business Intelligence Dashboard

NEXA — Business Intelligence Dashboard

Dashboard interativo desenvolvido como projeto de portfólio para explorar novas formas de apresentação de informações executivas, relatórios e indicadores de negócio.

O projeto simula um cenário corporativo e apresenta informações de forma visual e interativa, utilizando tecnologias web e conceitos de Business Intelligence.

🎯 Objetivo

Demonstrar como informações de negócio podem ser organizadas e apresentadas em uma interface web, criando uma alternativa visual para apresentações executivas tradicionalmente realizadas em PowerPoint ou Excel.

O projeto também explora o uso de Inteligência Artificial como apoio ao desenvolvimento.

📌 Estrutura do dashboard

O projeto possui diferentes áreas de análise:

Overview
Visão geral dos principais indicadores.

Financeiro
Análise de receita, custos, lucro e margem.

Vendas
Indicadores de pedidos, conversão, ticket médio e canais de venda.

Clientes
Análise de clientes ativos, novos clientes, retenção e segmentos.

Produtos
Análise de produtos, unidades vendidas, receita e margem.
